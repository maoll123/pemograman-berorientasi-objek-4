3. Konsep Singkat 
A. Association 
Association merupakan hubungan antarobject yang saling berinteraksi. 
Contoh: 
Mahasiswa -------- Dosen 
Contoh implementasi: 
class Mahasiswa { 
 
    private String nama; 
    private Dosen dosenWali; 
} 
Object Mahasiswa memiliki referensi terhadap object Dosen. 
 
B. Aggregation 
Aggregation menunjukkan hubungan has-a, tetapi object yang menjadi bagian masih dapat 
hidup secara mandiri. 
Contoh: 
Jurusan ◇------ Dosen 
Dosen tetap dapat ada meskipun object Jurusan tidak ada. 
Implementasi: 
class Jurusan { 
 
    private String nama; 
    private Dosen ketuaJurusan; 
 
    public Jurusan( 
        String nama, 
        Dosen ketuaJurusan 
    ) { 
        this.nama = nama; 
        this.ketuaJurusan = 
            ketuaJurusan; 
    } 
--- PAGE ---
} 
 
C. Composition 
Composition merupakan hubungan yang lebih kuat. 
Object bagian bergantung pada object pemilik. 
Contoh: 
Rumah ◆------ Ruangan 
Ruangan dianggap sebagai bagian dari Rumah. 
Contoh: 
class Rumah { 
 
    private Ruangan ruangTamu; 
 
    public Rumah() { 
        ruangTamu = 
            new Ruangan( 
                "Ruang Tamu" 
            ); 
    } 
} 
Object Ruangan dibuat di dalam Rumah. 
 
4. Perbandingan Relasi 
Relasi Hubungan Ketergantungan 
Association uses-a Lemah 
Aggregation has-a Sedang 
Composition part-of Kuat 
Pertanyaan utama saat menentukan relasi: 
Apakah object bagian masih dapat berdiri sendiri jika object utama dihapus? 
Jika ya, kemungkinan aggregation. 
Jika tidak, kemungkinan composition.

17. Definition of Done 
Tugas P4 selesai apabila: 
• Menggunakan project P3. 
• Minimal 4 class digunakan. 
• Relasi antarclass telah dianalisis. 
• Class diagram diperbarui. 
• Minimal 1 association diterapkan. 
• Minimal 1 aggregation diterapkan. 
• Minimal 1 composition diterapkan atau disertai argumentasi jika tidak relevan. 
• Object berinteraksi melalui method. 
• Tidak mengakses attribute private secara langsung. 
• Program berhasil dikompilasi. 
• Program berhasil dijalankan. 
• Minimal 3 skenario pengujian tersedia. 
• Sprint Backlog diperbarui. 
• Sprint Review tersedia. 
• Sprint Retrospective tersedia.
